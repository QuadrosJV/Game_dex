Sobre o projeto:
GameDex, app desenvolvido para apresentar um catalogo de jogos, feito para uma avaliação "AP2".
Nele da para ver as capas dos jogos, ano de lançamentos e as notas dos jogos, clicando em um jogo da para ver mais detalhes sobre ele.

Como foi feito:
O aplicativo foi desenvolvido em Kotlin usando Jetpack Compose para criar as telas.
Os jogos ficam cadastrados no proprio codigo, no arquivo JogoRepository.kt, totalizando 10 jogos.

Para carregar as imagens, utilizamos a biblioteca Coil. Para navegar entre a lista e os detalhes dos jogos, utilizamos Navigation Compose.
